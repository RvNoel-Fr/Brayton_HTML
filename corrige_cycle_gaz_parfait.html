Corrigé — Exercice 1

Cycle d'un gaz parfait monoatomique en système fermé

États du cycle

Nombre de moles : n = p₁V₁/(R·T₁) = (5×10⁵ × 0,6)/(8,31 × 400) = 90,3 mol (nR = p₁V₁/T₁ = 750 J·K⁻¹).

État 2 (détente isotherme) : T₂ = T₁ = 400 K et p₂ = p₁V₁/V₂ = 5 bar × 0,6/3 = 1,0 bar = 1,0×10⁵ Pa.

État 3 : V₃ = V₂ = 3 m³ (transformation 2→3 isochore).

Q1 — Diagramme p–V du cycle

Cycle parcouru dans le sens horaire (moteur) : 1→2 isotherme, 2→3 isochore, 3→1 adiabatique réversible.

Q2 — Pression et température de l'état 3

Gaz monoatomique : cpm = cVm + R = (5/2)·R, donc γ = cp/cV = 5/3.

Adiabatique réversible 3→1 : p·V^γ = cte et T·V^(γ−1) = cte.

p₃ = p₁·(V₁/V₃)^γ = 5×10⁵ × (0,6/3)^(5/3) = 3,42×10⁴ Pa ≈ 0,342 bar
T₃ = T₁·(V₁/V₃)^(γ−1) = 400 × (0,2)^(2/3) = 136,8 K ≈ 137 K

Vérification par l'isochore 2→3 : p₃ = p₂·T₃/T₂ = 1 bar × 136,8/400 ≈ 0,342 bar ✓ (ou p₃V₃ = nRT₃).

Q3 — Travail W, variation d'énergie interne ΔU et chaleur Q

Premier principe en système fermé : ΔU = W + Q (W, Q > 0 reçus par le gaz).

n·cVm = (3/2)·nR = (3/2) × (p₁V₁/T₁) = (3/2) × 750 = 1125 J·K⁻¹.

1→2 : détente isotherme (T = 400 K)

ΔU₁₂ = n·cVm·(T₂ − T₁) = 0
W₁₂ = −∫p dV = −nRT₁·ln(V₂/V₁) = −p₁V₁·ln(V₂/V₁) = −(5×10⁵)(0,6)·ln(3/0,6) = −4,83×10⁵ J
Q₁₂ = −W₁₂ = +4,83×10⁵ J (chaleur reçue par le gaz)

2→3 : refroidissement isochore (V = 3 m³)

W₂₃ = 0 (volume constant)
ΔU₂₃ = n·cVm·(T₃ − T₂) = 1125 × (136,8 − 400) = −2,96×10⁵ J
Q₂₃ = ΔU₂₃ = −2,96×10⁵ J (chaleur cédée par le gaz)

3→1 : compression adiabatique réversible

Q₃₁ = 0 (adiabatique)
W₃₁ = ΔU₃₁ = n·cVm·(T₁ − T₃) = 1125 × (400 − 136,8) = +2,96×10⁵ J

Vérification : W₃₁ = (p₁V₁ − p₃V₃)/(γ−1) = (3,00×10⁵ − 1,026×10⁵)/(2/3) = +2,96×10⁵ J ✓

Vérifications

  • Sur un cycle, ΔU = 0 et Q_cycle = −W_cycle = +1,87×10⁵ J : le gaz fournit un travail net de 1,87×10⁵ J par cycle (parcours horaire : le cycle est moteur).
  • Si la machine est utilisée comme moteur thermique : η = |W_cycle| / Q_reçue = 1,87×10⁵ / 4,83×10⁵ ≈ 0,387, soit 38,7 %.
