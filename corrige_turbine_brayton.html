Corrigé — Turbine à gaz : cycle de Brayton ouvert

Premier principe en système ouvert — calculs par unité de masse

Convention et rappel

Premier principe en système ouvert, régime permanent, par unité de masse :  Δh = q + w

q > 0 et w > 0 lorsqu'ils sont reçus par le fluide ; négatifs lorsqu'ils sont fournis/rejetés. h = cp·T avec cp = 1,0 kJ·kg⁻¹·K⁻¹.

Q1 — Températures aux points du cycle

Point 2 (compression adiabatique réversible 1 → 2)

T₂ = T₁·(P₂/P₁)(γ−1)/γ

AN : T₂ = 300 × 82/7 = 300 × 1,8114 = 543,4 K (≈ 270 °C)

Point 3 (combustion isobare 2 → 3)

Dans la chambre de combustion il n'y a pas de pièce mobile : w₂₃ = 0. Le premier principe donne :

Δh₂₃ = q₂₃ = qc  →  cp(T₃ − T₂) = qc  →  T₃ = T₂ + qc/cp

AN : T₃ = 543,4 + 1100/1,0 = 1643,4 K (≈ 1370 °C)

Point 4 (détente adiabatique réversible 3 → 4)

T₄ = T₃·(P₄/P₃)(γ−1)/γ = T₃·(1/8)2/7

AN : T₄ = 1643,4 / 1,8114 = 907,2 K (≈ 634 °C)

Q4 — Travail utile massique et rendement

Le travail utile massique fourni par la machine est l'opposé du travail net reçu par le fluide :

wu = −(w₁₂ + w₃₄) = −(243,4 − 736,2) = +492,8 kJ·kg⁻¹

Vérification : sur un cycle, ΣΔh = 0 donc Σq + Σw = 0, d'où wu = −Σw = Σq = 1100 − 607,2 = 492,8 kJ·kg⁻¹ ✓

Rendement :  η = wu / q₂₃ = 492,8 / 1100 = 0,448, soit η ≈ 44,8 %

Vérification (cycle de Brayton idéal) : η = 1 − T₁/T₂ = 1 − 300/543,4 = 1 − (P₁/P₂)(γ−1)/γ ≈ 0,448 ✓

Q5 — Puissance utile fournie

P = D · wu = 50 kg·s⁻¹ × 492,8 kJ·kg⁻¹ = 24 640 kW ≈ 24,6 MW

Remarques

  • Le compresseur absorbe w₁₂/w₃₄ = 243,4/736,2 ≈ 33 % du travail produit par la turbine : le travail utile n'est que la différence des deux.
  • La chaleur rejetée à l'échappement vaut |q₄₁| = 607,2 kJ·kg⁻¹, soit environ 55 % de l'énergie de combustion : c'est la principale perte du cycle ouvert.
  • Le rendement ne dépend ici que du taux de compression : η = 1 − (P₁/P₂)(γ−1)/γ.
